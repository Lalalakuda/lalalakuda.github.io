## 見出しと段落

`## ` で始めると大見出し、`### ` で小見出しになります。空行で段落が分かれます。

## コード

```python
# 熱電圧 kT/q を求める
k = 1.380649e-23   # ボルツマン定数 [J/K]
q = 1.602176634e-19  # 電気素量 [C]
T = 300
print(f"kT/q = {k * T / q * 1000:.2f} mV")
```
